# Credit Card Fraud Detection Under Extreme Class Imbalance

COSC 50303 Data Mining — Fall 2026  
Student: Tanka Raj Joshi

## Project Goal
Study credit card fraud detection under extreme class imbalance using supervised classification and anomaly detection.

## Current Phase
Phase 1 — Data Understanding and Exploratory Data Analysis (EDA)

## Planned Workflow
1. Data understanding and exploratory analysis
2. Data-quality and leakage checks
3. Hold-out test set
4. Cross-validation on development data
5. Logistic Regression baseline
6. XGBoost
7. Isolation Forest
8. Class-imbalance and threshold analysis
9. Final untouched-test evaluation
10. Error analysis and reproducibility

## Dataset
ULB Credit Card Fraud Detection dataset.

The raw dataset is not stored in this repository. It will be attached as input in Kaggle or loaded from a local path.
